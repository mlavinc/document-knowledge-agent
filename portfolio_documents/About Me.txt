## Building Real Systems

My portfolio is centered around projects that simulate real engineering environments rather than academic exercises.

### ThermoSim

One of the projects I'm most proud of.

ThermoSim is a distributed numerical solver written in Java for the two-dimensional heat equation. I implemented the mathematical core myself using finite differences, Jacobi iteration, and parallelization with ForkJoinPool, then deployed the complete distributed architecture on AWS using ECS Fargate, Amazon SQS, S3, DynamoDB, and CloudWatch.

For me, this project represents the intersection between applied mathematics, distributed systems, cloud computing, and software engineering.

### Cloud Operations Lab

A production-inspired AWS environment built entirely with Terraform.

The project focuses on Infrastructure as Code, networking, IAM, EC2, Systems Manager, CloudWatch, GitHub Actions, and cloud operational practices. Rather than simply provisioning resources, the goal was to understand how infrastructure can be versioned, automated, secured, and maintained following modern DevOps principles.

### ECG AI Serverless

A complete machine learning pipeline for ECG classification using Scikit-learn, deployed as a serverless application with AWS Lambda, API Gateway, and Amazon S3.

Beyond building the model itself, the project explores how machine learning solutions can be packaged and deployed as scalable cloud services.

### Skill Tracker

A full-stack application developed with Go, React, PostgreSQL, and Docker.

The project allowed me to explore backend development, API design, relational databases, containerization, and modern frontend integration while keeping the architecture clean and maintainable.

In parallel, I'm also developing a **Document RAG Agent**, combining FastAPI, vector databases, retrieval-augmented generation, and cloud-native deployment patterns to explore how modern AI systems can retrieve and reason over technical documentation.
