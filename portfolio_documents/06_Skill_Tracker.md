# 06 — Project: Skill Tracker

## Overview

**Skill Tracker** is a full-stack portfolio project by Martín Lavín (Martin Lavin) for tracking skills, practice sessions, progress, and competitive rankings.

Repository: github.com/mlavinc/skill-tracker

## What it does

Users can track skills and practice progress through a web application with a REST API backend, relational database, and containerized local development. Cloud deployment patterns include Vercel (frontend) + Render (API) + Neon (PostgreSQL).

## Technology stack

| Layer | Technology |
|---|---|
| Frontend | React + Vite |
| Backend | Go (`net/http`) |
| Database | PostgreSQL |
| Local orchestration | Docker + Docker Compose |
| Cloud options | Vercel, Render, Neon |
